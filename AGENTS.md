# AgentUIKit

Swift 6, strict concurrency, macOS 27. Run `swift build` and `swift test`.
No app imports or implicit app/global settings. UI receives presentation values
and typed actions; execution and storage belong below the presentation layer.
Use DesignKit for shared visual components when adding views. Preserve scroll,
keyboard, accessibility, and interaction behavior through characterization tests.

CI is generated by CodeEditor/Scripts/sync-package-ci. The initial product owns
only transcript scroll policies, not a placeholder assistant implementation.
